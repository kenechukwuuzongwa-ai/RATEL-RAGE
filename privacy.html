Privacy

RATEL RAGE by KenCrafts Interactive Studio · last updated 10 October 2026

We collect a little anonymous gameplay data to see how many play, where it is too hard, and what breaks. We never collect your name, email, phone number, contacts, precise location or IP address. No advertising tracking.

What the game sends

  • Gameplay events: session start, a one-minute "still playing" signal while on screen, level start, Darki knocked out (level and arena section), retry, quit, and level finish (time, score, rank).
  • Device type, not identity: mobile / tablet / desktop, browser and OS (with versions), language, screen size, and a rough memory / CPU class.
  • Performance and errors: load time, frames per second, and error text (message and file name only).
  • Country: the two-letter code our host (Cloudflare) attaches to each request. Nothing more precise.
  • Random IDs: one per tab session, plus a random player ID in your browser's storage so returning players count once. Not linked to who you are. With "Do Not Track" or "Global Privacy Control" on, no player ID is stored.

Page-visit counts

Cloudflare Web Analytics counts page visits without cookies or identifying visitors.

Billboards

Some in-game billboards show paid adverts, fetched from our ad server. For advertisers it counts, per board per day, how often a board was on screen and its pause-menu link opened. Totals only: no ID, account, device details or anything about you is sent.

Storage and retention

On Cloudflare's servers, readable only by the developer. Gameplay events are deleted after 180 days, session summaries after 400. Used only to improve the game; never sold or shared.

Your choices

Clearing this site's browser data deletes the player ID; "Do Not Track" or "Global Privacy Control" stops it being created. Questions or deletion requests: contact KenCrafts Interactive Studio.
