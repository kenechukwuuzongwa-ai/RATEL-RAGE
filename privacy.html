Privacy

RATEL RAGE by KenCrafts Interactive Studio · last updated 10 October 2026

We collect a small amount of anonymous gameplay data to see how many people play, where the game is too hard, and what breaks. We never collect your name, email, phone number, contacts, precise location or IP address, and there is no advertising tracking.

What the game sends

  • Gameplay events: a session starting, a one-minute "still playing" signal while the game is on screen, starting a level, Darki being knocked out (with the level and arena section), retrying, quitting, and finishing a level (time, score, rank).
  • Device type, not device identity: mobile / tablet / desktop, browser family and version, operating system and version, language, screen size, and a rough memory / CPU class.
  • Performance and errors: how long loading took, frames per second, and the text of any error the game hits (message and file name only).
  • Country: the two-letter country code our host (Cloudflare) attaches to each request. Nothing more precise.
  • A random ID: one per browser tab session, and one random player ID kept in your browser's storage so returning players can be counted once. It is not linked to who you are. If your browser sends "Do Not Track" or "Global Privacy Control", no player ID is stored.

Page-visit counts

The website also uses Cloudflare Web Analytics, which counts page visits without cookies and without identifying visitors.

Billboards

Some billboards in the game show paid adverts. To show them, the game asks our ad server which advert each board carries. To report results to advertisers it counts, per board and per day, how many times a board was on screen and how many times its pause-menu link was opened. These are totals only: no ID, no account, no device details and nothing about you is sent with them.

Where it is kept, and for how long

On Cloudflare's servers, readable only by the developer. Gameplay events are deleted after 180 days and session summaries after 400 days. The data is used only to improve the game. It is not sold or shared.

Your choices

Clearing this site's data in your browser deletes the player ID. Turning on "Do Not Track" or "Global Privacy Control" stops it being created. Questions or deletion requests: contact KenCrafts Interactive Studio.
